# Sara Izquierdo — Portafolio personal académico

Sitio web estático creado para el proyecto de página personal del Semillero Singularidad.

## Publicar con GitHub Pages

1. Entra a github.com e inicia sesión (o crea una cuenta).
2. Selecciona **New repository** y nómbralo, por ejemplo, `sara-izquierdo`.
3. Selecciona **Public** y crea el repositorio.
4. En la pestaña **Code**, selecciona **Add file → Upload files**.
5. **Descomprime este ZIP primero** y sube `index.html`, `style.css`, `script.js`, `comunidad.png` y `README.md` directamente a la raíz del repositorio. No subas el ZIP sin descomprimir.
6. Selecciona **Commit changes**.
7. En **Settings → Pages**, dentro de **Build and deployment**, elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y guarda.
8. Espera unos minutos: el enlace será `https://TU-USUARIO.github.io/sara-izquierdo/` si ese es el nombre elegido para el repositorio.

## Modificar

- Textos y correo: `index.html`.
- Estilo y colores: `style.css`.
- Contador e interacción del mapa de intereses: `script.js`.
- Ilustración comunitaria: `comunidad.png`.

## Notas de integridad académica

- La portada del proyecto de grado es conceptual: no representa una publicación científica real.
- La ilustración comunitaria está generada con IA y no representa personas reales de la comunidad.
- No se atribuyen publicaciones ni resultados de investigación.
- La fecha y la hora de nacimiento están en el código JavaScript para calcular la edad, **aunque no se muestran en pantalla**. Quien inspeccione el código público puede verlas. Si quieres ocultarlas también del repositorio, reemplaza el contador por uno aproximado o por una edad no actualizable: en un sitio estático no pueden permanecer secretas y alimentar un contador exacto.
- Las fuentes tipográficas de Google Fonts requieren conexión a Internet; hay fuentes alternativas de sistema.
